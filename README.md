# AI Smart Study Planner

Course: CSE 4104 - Software Development III
Team Name: CSE4104-7E-T06 | Section: 7E

## Project Description

AI Smart Study Planner is a web application that helps university students organize their subjects, assignments and exam dates. Using Google Gemini AI, it analyzes the student's workload, subject difficulty, deadlines and available daily study time to generate a personalized 7-day study schedule with short explanations for its suggestions. Unlike a basic to-do list, it helps students decide what to study when to study and how to distribute preparation time across subjects.

## Proposed Features

- Authentication (register / login)
- Subject management with difficulty levels
- Assignment and exam management (deadline, estimated hours, status)
- Academic progress dashboard
- AI-powered weekly (7-day) study schedule generation with explanations
- Task and study session completion tracking
- Saved study plan management
